# Test Suite Specification & Strategy

## 1. Unit Testing

- **Auth Service:** Test password hashing (bcrypt), token validation, and payload validation.
- **Encryption Engine:** Test that client-side ciphertexts decrypt accurately back to original plain text and media byte streams.

## 2. Integration Testing

- **WebSocket Handshake:** Test connection rejection when JWT is invalid or expired.
- **Message Pipeline:** Test message delivery between User A and User B over socket channels.
- **Media Upload:** Test pre-signed URL generation and file metadata storage.

## 3. E2E (End-to-End) Tests

- User Registration -> User Login -> Search Username -> Send Encrypted Text/Image -> Receive & Decrypt on Receiver device.

## 4. Performance & Load Tests

- **Concurrent Connections:** Benchmark WebSocket server with 10,000 active socket connections using k6/Autocannon.
