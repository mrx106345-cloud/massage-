# Incident Response & Security Runbook

## 1. Compromised User Account / Token Leak

1. Invalidate active JWTs by incrementing the user's `token_version` in PostgreSQL.
2. Force disconnect all active WebSockets associated with the target `user_id`.
3. Require password reset via email verification.

## 2. Data Breach Assessment

- Since messages and media files are stored encrypted on disk and in cloud storage, compromised database records yield only encrypted ciphertexts, public keys, and metadata handles.

## 3. Emergency Maintenance Mode

- Set `MAINTENANCE_MODE=true` in environment variables to reject incoming WebSocket handshakes with HTTP 503 and block non-essential API endpoints.
