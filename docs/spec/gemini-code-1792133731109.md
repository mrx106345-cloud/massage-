# API Specification

## Authentication Endpoints

- `POST /api/v1/auth/signup`
  - Body: `{ "email": "user@example.com", "password": "securepassword", "username": "johndoe" }`
  - Response: `{ "token": "JWT_TOKEN", "user": { "id": "uuid", "username": "johndoe" } }`

- `POST /api/v1/auth/login`
  - Body: `{ "email": "user@example.com", "password": "securepassword" }`
  - Response: `{ "token": "JWT_TOKEN", "user": { "id": "uuid", "username": "johndoe" } }`

## Chat & Group Endpoints

- `GET /api/v1/users/search?q=username` - Search user by username
- `POST /api/v1/groups` - Create a new group (`{ "group_name": "Devs", "member_ids": [...] }`)
- `POST /api/v1/media/presign` - Request secure upload URL for media (`{ "file_type": "image/png" }`)

## WebSocket Events

- `join_room`: Connects user to specific 1-to-1 or group chat channels.
- `send_message`: Emits encrypted payload to recipient/group.
- `receive_message`: Delivers message packet to client.
