# Security & Privacy Guardrails

1. **Password Storage:** Passwords must be hashed using `bcrypt` with a minimum salt round of 12. Plain text passwords must never be logged or saved.
2. **Encryption:** All chat payloads must be encrypted client-side using symmetric/asymmetric keys before transmission over WebSockets.
3. **Media Protection:** Uploaded images, videos, and audio must be encrypted client-side prior to hitting S3 storage. Pre-signed URLs must expire within 15 minutes.
4. **Rate Limiting:** Auth endpoints (`/login`, `/signup`) must implement strict IP-based rate limiting to prevent brute-force attacks.
