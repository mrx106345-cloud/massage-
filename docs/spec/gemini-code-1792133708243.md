# Secure Messaging App - Cursor Rules

## Tech Stack

- Frontend: Flutter (Cross-platform mobile) / React.js (Web)
- Backend: Node.js (Express) + WebSockets (Socket.io)
- Database: PostgreSQL + Redis (for real-time presence/session cache)
- Storage: AWS S3 or Cloudinary (Encrypted media storage)

## Core Principles

- **Privacy First:** Zero plaintext storage of messages or media on the server.
- **E2EE:** Client-side encryption using AES-256 / Signal protocol.
- **Clean Code:** Modular architecture separating routes, controllers, services, and sockets.
- **Error Handling:** Graceful failure handling on network drops with automatic WebSocket reconnection.
