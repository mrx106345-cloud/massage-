# AI & Data Privacy Guidelines

1. **No AI Training on Message Data:** User chats, images, audio, and videos are fully encrypted end-to-end and must never be used for machine learning or LLM training.
2. **Metadata Minimization:** Server logs must mask IP addresses and store minimal telemetry (only timestamp and encrypted payload size).
3. **Data Retention:** Messages kept in offline queues are purged from memory immediately upon delivery verification.
