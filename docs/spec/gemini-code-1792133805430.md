# Multi-Agent Workflow Specification

## Agents Architecture

1. **Security Lead Agent:**
   - _Role:_ Validates key exchange protocols, crypto libraries, and ensures zero plain-text leaks on backend or logs.
2. **Backend & Socket Agent:**
   - _Role:_ Implements Node.js REST APIs, PostgreSQL queries, Redis caching, and Socket.io event channels.
3. **Frontend / Mobile Agent:**
   - _Role:_ Builds Flutter/React UI components, local key storage (Keychain/Keystore), and client-side encryption modules.
4. **QA & Penetration Test Agent:**
   - _Role:_ Generates mock E2E test cases, tests WebSocket load handling, and validates media pre-signed URL expiration.
