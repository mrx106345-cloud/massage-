# Product Requirements Document (PRD): Secure Chat App

## 1. Objective

Build a lightweight, end-to-end encrypted instant messaging application supporting text, rich media (images, videos, audio), 1-to-1 chats, and group chats, authenticated strictly via Email, Password, and a unique Username.

## 2. User Stories

- **US-01:** As a new user, I can register using an Email, Password, and a unique Username.
- **US-02:** As a registered user, I can log in securely and maintain an active session via JWT.
- **US-03:** As a user, I can search for other users by username and start a 1-to-1 chat.
- **US-04:** As a user, I can create a group chat, add members, and send broadcast messages.
- **US-05:** As a user, I can send and receive text, images, videos, and audio notes securely.
- **US-06:** As a user, my messages are end-to-end encrypted so that the server cannot read them.
